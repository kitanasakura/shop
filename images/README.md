# /images/
Upload your files here (logo, hero banner, product photos, category icons).
Then use just the file name in the /specs/*.md files, e.g. `- images: kuromi-1.jpg, kuromi-2.jpg`
Tips: JPG/WebP for photos (under ~300 KB each), PNG with transparent background for logo + category icons.
Names are case-sensitive on GitHub Pages: `Kuromi.JPG` is not `kuromi.jpg`.
